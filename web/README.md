类微信的 AI 智能体团队协作客户端。在这里你是唯一的真人——「老板」，通讯录里是一群各怀绝技的 AI 智能体：单聊交代任务、拉群推进项目，编排者会自动分工协作，全过程像聊天记录一样透明可见。

## 相关仓库

- 后端服务 [agent-team-server](https://github.com/guyu0327/agent-team-server)：Spring Boot 4 + AgentScope 2，负责智能体编排、LLM 流式接入与文件沙箱
- 桌面壳 [agent-team-desktop](https://github.com/guyu0327/agent-team-desktop)：Electron 打包分发，注入 API 地址/令牌并提供原生文件选择与备份恢复

## 功能特性

### 消息
- 单聊 / 群聊，SSE 流式输出逐字呈现，输入中状态提示
- 智能体消息 Markdown 渲染：代码块、表格、列表、引用、链接等，均为暗色优化
- 贴近微信群聊的回复规则：@谁谁回；没人被 @ 时全员依次接龙
- 群聊自由讨论模式：群聊菜单一键开关（建群时也可直接指定），开启后成员自动接龙讨论、无需逐个 @，可随时终止
- 回复时自动滚动跟随：向上翻阅即暂停，回到底部自动恢复，并有一键回底按钮
- 会话置顶、重命名、删除、消息重置、未读计数
- 右键菜单：会话列表右键置顶 / 标记已读 / 重命名（群聊）/ 清空记录 / 删除；消息气泡右键复制文字，点在图片上可复制图片
- 输入框附件按钮（文件/文件夹）调用系统资源管理器原生对话框选择本机路径（需桌面壳环境），文件可多选，智能体即可对该路径读写；气泡内展示附件卡片，「会话文件授权」弹层可查看/撤销本会话授权
- 拖拽文件/文件夹到输入框即可快速添加为附件（需桌面壳环境），文件与文件夹可混拖，自动识别类型并去重
- 图片附件直接可被智能体「看懂」：附加图片（png/jpg/jpeg/gif/webp/bmp）后，支持视觉的模型可直接理解图片内容；气泡内图片附件渲染为缩略图，点击新窗口查看原图，输入框附件 chip 显示小缩略图预览
- 实时语音转写（讯飞流式听写）：按住输入框麦克风即开始边说边出字，识别文本实时刷新到输入框，松手即结束并补全尾句（保留已出文字，Esc 同效）；前端 AudioWorklet 采集重采样为 16k PCM，经后端 `/api/asr/stream` WebSocket 桥接讯飞流式听写，停顿约 1 秒自动断句，单次最长 60 秒自动结束；未配置时按下麦克风跳转设置页
- 受控操作审批卡片：智能体要写入/修改文件或执行终端命令时，回复暂停并弹出审批卡片，展示发起智能体、目标文件与完整内容/命令，可选「允许一次 / 本会话允许 / 拒绝」，120 秒未响应自动按拒绝处理
- 文生图：智能体绑定图像预设后即获得 `generate_image` 生图工具，生成过程与图片结果像聊天一样自然呈现——回复中的工作区图片路径自动渲染为可查看的图片

### 通讯录
- 智能体管理：头像、名称、分组、描述、角色设定（System Prompt）、温度
- 编排者标识：列表角标 + 详情页徽标
- 按分组折叠展示，折叠状态本地记忆
- 一键发起会话

### 模型预设
- 统一管理 API 地址 / API Key / 模型名，多个智能体复用同一预设
- 按类型区分：对话（OpenAI 兼容）与文生图（阿里 DashScope / OpenAI Images 兼容 / 硅基流动）；智能体可单独绑定图像预设获得生图能力
- 通讯录式布局：左列表按「对话预设 / 文生图预设」分组折叠展示，右侧详情卡查看配置与使用中的智能体，新建/编辑为独立表单页
- 模型控制台：列表底部一键跳转 DeepSeek / 阿里云百炼 / 硅基流动 / OpenAI 等十个主流平台的控制台（系统浏览器打开）
- 密钥加密存储且永不回传：列表与编辑框只显示「已配置 / 未配置」，编辑时留空表示保持不变

### 编排协作可视化
- 编排者协调时显示状态条（呼吸灯动画）
- 编排者多段发言、成员实时输出、总结回单聊——协作可能跨会话进行，前端按事件中的会话 ID 自动路由

### 设置
- 文件沙箱配置：主工作区目录 + 白名单目录，支持系统资源管理器选择，保存后对智能体立即生效
- 实时语音识别配置：讯飞开放平台（xfyun.cn）应用的 APPID / APIKey / APISecret（需开通「语音听写」，每天 500 次免费），保存后按住麦克风即可实时转写；密钥保存后不再显示，留空表示保持不变，全部留空保存则清除配置
- 数据管理（需桌面壳环境）：导出备份（数据库快照 + 工作区文件）/ 从备份恢复 / 打开数据目录
- 关于：日期版本号（如 v2026.09.16），点击查看按日期排序的更新日志；GitHub 图标跳转仓库页面

## 快速开始

环境要求：Node.js 20.19+，以及运行中的后端服务（默认 `http://localhost:8080`，见相关仓库）。

```bash
npm install
npm run dev
```

浏览器访问 <http://localhost:5173>。开发服务器已配置代理 `/api → http://localhost:8080`，无需处理跨域。

生产构建：

```bash
npm run build    # vue-tsc 类型检查 + 打包到 dist/
npm run preview  # 本地预览构建产物
```

## 目录结构

```
src/
├── api/            后端接口封装（base / http / desktop / user / agent / conversation / modelPreset / settings / fs / asr）
├── components/     通用组件（头像、气泡、搜索栏、确认弹窗等）
├── composables/    组合式函数
├── layouts/        主布局（侧边导航）
├── router/         路由
├── stores/         Pinia 状态（会话、智能体、用户、模型预设）
├── styles/         SCSS 设计变量
├── types/          类型定义
├── utils/          工具（Markdown 渲染等）
└── views/          页面（message / chat / contact / profile）
```
